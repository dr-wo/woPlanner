# Race Info

The live window has **Live** and **Race Info** tabs. Race Info shows **Race Control Events**, followed by **Pit Delta**. Choose All events, Penalty, or Lap time deleted to filter the notice table. Rows retain the original message, source notification lap, car number (source RacingNumber, or explicit CAR number in the message), and additional source fields. Event times are UTC. Missing event times display a dash and remain after dated notices; receive and playback clocks never substitute for event time.

Pit Delta contains the existing independent Green, SC and VSC inputs and Apply pit losses action. Selection, plot/map windows, operational event binding, persistence, unresolved values, and calculations are unchanged. Select a driver in Live to see the windows. Switching back to Live refreshes the embedded map even if playback has stopped.

## Source and semantics

Race operation subscribes to the existing F1 `RaceControlMessages` topic, which archive replay already supports. The race reducer now exposes immutable `race_control_events` on `LiveSessionSnapshot`; an independent `race_control` change notification refreshes the table without rerunning strategy or plot calculations. Source indices reconcile list subscription snapshots and sparse indexed patches. Identical repeat delivery updates the existing row; identical complete timestamped notices with different indices are displayed once. Different notices with the same time are retained. Older source-coordinate patches cannot overwrite newer field corrections, but can supply previously missing fields. Unknown fields are retained and displayed.

Penalty and deleted-lap labels classify the text of a notice; the original message remains authoritative (including served, corrected, or other wording). The list includes flags, investigations and all other notices, not only the two new categories. These messages **do not apply a sporting penalty, remove completed laps, or alter strategy/classification**. The source `Lap` is the notification race lap, which may differ from the affected lap in the message. For example, R17's RUS notice published at race lap 53 concerns lap 51; the HAM/NOR notices published at race lap 55 concern lap 54.

Old live recordings cannot recover notices that were never subscribed to. Both local R17 raw race recordings have no RaceControlMessages entries. The committed R17 L52–L55 fixture comes from the existing historical Race Control CSV (`research/r17_ham_20261011/inputs/race_control_messages.csv`), preserves original messages, and maps its UTC Time column to the source Utc field. This fixture validates historical messages via the recorded replay path as well as live ingestion. There are no penalty notices in that CSV, so penalty tests are explicitly synthetic. No external dependency or download was added.
